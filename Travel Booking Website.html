About TravelGo

TravelGo is a sample Travel Booking Management System developed using HTML, CSS and JavaScript.


Users can search for flights, book hotels, explore tour packages and manage their bookings.


This project is designed as a simple educational Web Technology project that can be opened directly in VS Code and a web browser.


Technology: HTML5, CSS3, JavaScript and Browser LocalStorage.
